## 📝 Documentation Standards

When adding new documentation:

1. **Location**: Place in appropriate subdirectory
2. **Naming**: Use UPPERCASE_WITH_UNDERSCORES.md format
3. **Headers**: Start with # and use proper hierarchy
4. **TOC**: Add table of contents for long docs
5. **Code**: Use syntax highlighting in code blocks
6. **Links**: Use relative links within docs
7. **Update**: Update this README when adding new docs
